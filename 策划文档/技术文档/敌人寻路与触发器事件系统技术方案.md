# 敌人寻路与触发器事件系统技术方案

> 版本：v1.0
> 关联模块：`src/game-scene.js`、`src/state.js`、`src/main.js`、`src/api.js`

## 1. 概述

本次迭代包含两块能力：

1. **敌人寻路**：敌人不再直线穿墙，而是自动绕开面前的墙体（轴对齐矩形墙），朝玩家寻路。
2. **触发器事件系统**：触发器由"通关标记"扩展为通用事件钩子。玩家进入触发器范围后，按配置触发不同事件。首批事件：
   - `spawnEnemy` 召唤敌人（屏幕外生成 / 玩家周围生成）
   - `switchLevel` 切换关卡（渐变过渡）

技术选型（已确认）：

| 决策点 | 结论 |
| --- | --- |
| 触发器触发机制 | 可配置：一次性 / 可重复（每次进入触发） |
| 切换关卡目标 | 触发器直接指定目标关卡 ID + 玩家出生点 |
| 敌人绕墙方案 | 网格 A* 寻路（墙体为轴对齐矩形） |
| 圆形生成配置 | 独立 `shape` 字段区分 `polygon` / `circle` |

## 2. 需求清单

### 2.1 敌人寻路

- 敌人朝玩家移动时，若视线被墙体遮挡，自动规划路径绕墙。
- 墙体为轴对齐矩形，膨胀敌人碰撞半径后作为不可走区域。
- 寻路只作用于"朝玩家移动"阶段，不影响既有环绕/冲刺等行为。

### 2.2 触发器事件

- 触发器是关卡中的一个范围（轴对齐矩形）。
- 玩家进入范围触发对应钩子，产生事件。
- 触发模式可配置：一次性 / 可重复（每次进入触发，可配冷却）。

### 2.3 事件一：召唤敌人

- **屏幕外生成**：在玩家屏幕外 10px 位置生成指定种类、数量的敌人；位置随机，但不得落在墙体内。
- **玩家周围生成**：以玩家为中心绘制动态多边形（等距顶点，边数/半径可配置，边厚 10px，顺时针，0.5s 绘制完成）；每绘制出一个顶点即在该顶点生成一个敌人；绘制完成后顺时针消失。
- **圆形生成**：`shape = 'circle'` 时，按"圆形生成数量"在圆弧上均分生成敌人（绘制与消失逻辑同多边形，用圆弧代替折线）。

### 2.4 事件二：切换关卡

- 玩家进入范围后：当前关卡渐变消失 → 加载目标关卡 → 渐变显现。
- 目标关卡 ID 与切换后玩家出生点由触发器配置。

## 3. 数据模型

### 3.1 触发器 Trigger

在现有触发器结构上扩展：

```js
{
  id: 'trigger-1',
  x: 300, y: 300, w: 120, h: 90,   // 中心点 + 宽高（轴对齐矩形）
  color: '#f3b63f',
  visible: true,                     // 编辑器/游戏内是否可见
  action: 'spawnEnemy',              // 'complete' | 'spawnEnemy' | 'switchLevel'
  once: true,                        // true=一次性（默认），false=可重复
  cooldown: 0,                       // 可重复时的冷却，毫秒（可选）

  // action === 'spawnEnemy'
  spawn: {
    mode: 'surround',                // 'offscreen' | 'surround'
    enemyType: 'basic1',             // ENEMY_TYPES 中的 key
    count: 5,                        // offscreen 模式使用
    // mode === 'surround'
    shape: 'polygon',                // 'polygon' | 'circle'
    sides: 6,                        // polygon 边数
    radius: 120,                     // 顶点到玩家中心距离（世界单位）
    thickness: 10,                   // 边厚度，默认 10
    drawDuration: 500,               // 绘制时长 ms，默认 500
    fadeDuration: 500,               // 消失时长 ms，默认 500
    circleCount: 8                   // shape === 'circle' 时生成数量
  },

  // action === 'switchLevel'
  target: 'level-2',                 // 目标关卡 ID
  spawnPoint: { x: 130, y: 300 }     // 切换后玩家出生点（缺省用目标关卡 spawn）
}
```

`normalizeLevel` 中新增 `normalizeTrigger`，对缺失字段补默认值：

```js
export function normalizeTrigger(trigger, index) {
  const base = {
    id: trigger?.id || `trigger-${index + 1}`,
    x: Number(trigger?.x) || 0,
    y: Number(trigger?.y) || 0,
    w: Math.max(Number(trigger?.w) || 90, MIN_WALL_SIZE),
    h: Math.max(Number(trigger?.h) || 90, MIN_WALL_SIZE),
    color: trigger?.color || '#f3b63f',
    visible: trigger?.visible !== false,
    action: trigger?.action || 'complete',
    once: trigger?.once !== false
  };

  if (base.action === 'spawnEnemy') {
    const s = trigger?.spawn || {};
    base.spawn = {
      mode: s.mode === 'offscreen' ? 'offscreen' : 'surround',
      enemyType: ENEMY_TYPES[s.enemyType] ? s.enemyType : 'basic1',
      count: Math.max(1, Number(s.count) || 5),
      shape: s.shape === 'circle' ? 'circle' : 'polygon',
      sides: Math.max(3, Number(s.sides) || 6),
      radius: Math.max(20, Number(s.radius) || 120),
      thickness: Math.max(1, Number(s.thickness) || 10),
      drawDuration: Math.max(0, Number(s.drawDuration) || 500),
      fadeDuration: Math.max(0, Number(s.fadeDuration) || 500),
      circleCount: Math.max(1, Number(s.circleCount) || 8)
    };
  }

  if (base.action === 'switchLevel') {
    base.target = trigger?.target || '';
    base.spawnPoint = trigger?.spawnPoint
      ? { x: Number(trigger.spawnPoint.x) || 0, y: Number(trigger.spawnPoint.y) || 0 }
      : null;
  }

  return base;
}
```

## 4. 敌人寻路（网格 A*）

### 4.1 网格构建

- 网格单元复用 `CELL = 30`（世界单位）。
- 网格尺寸：`gridW = ceil(world.width / CELL)`，`gridH = ceil(world.height / CELL)`。默认 1920×1080 → 64×36 = 2304 格，规模极小。
- 阻塞判定：将每面墙体矩形按敌人碰撞半径 `r` 膨胀（`w + 2r, h + 2r`），与该矩形相交的格子标记为 `blocked`。
- 世界坐标 ⇄ 格子坐标换算：

```js
const toCell = (x, y) => ({ cx: Math.floor(x / CELL), cy: Math.floor(y / CELL) });
const toWorld = (cx, cy) => ({ x: (cx + 0.5) * CELL, y: (cy + 0.5) * CELL });
```

- 网格在 `restart()`（进入关卡）时构建一次，墙体为静态数据，无需每帧重建。

### 4.2 视线检测（LOS）

- 已有 `rayRectIntersect` 可复用：敌人中心 → 玩家中心的线段与所有墙体求交。
- 若不相交，说明视线通畅，敌人直接朝玩家移动（无需寻路）。
- LOS 检测在每个敌人每帧执行，成本低（墙体数量少）。

### 4.3 路径计算与跟随

A* 核心（4 向邻居，曼哈顿距离启发，可扩展 8 向 + 角点剪枝防止斜穿墙角）：

```
1. 若 LOS 通畅：清空 path，直接朝玩家移动。
2. 若 LOS 被挡：
   a. 需要重算时（path 为空 / pathIndex 越界 / 玩家移动超过阈值 / 周期 250ms）
      以敌人格子为起点、玩家所在格子（或玩家最近可走格子）为终点执行 A*。
   b. A* 失败（无路径，如被全封闭）→ 退回直冲玩家（原行为）。
   c. 将路径格子中心转为世界坐标 waypoint 数组。
3. 朝 path[pathIndex] 移动；到达（距离 < CELL*0.4）则 pathIndex++。
4. waypoint 走完且仍未通畅 → 重新 A*。
```

A* 实现为纯函数，独立模块，便于单测：

```js
// src/pathfinding.js
export function buildGrid(world, walls, cell, radius) { /* 返回 blocked 二维数组 */ }
export function findPath(grid, start, goal, blocked) { /* 返回格子数组或 null */ }
```

关键点：

- **终点兜底**：若玩家格子被标记 blocked（玩家贴墙），向玩家格子四周搜索最近的可走格子作为终点。
- **路径平滑**：生成 waypoint 后，若相邻两点间 LOS 通畅则合并（减少折线抖动）。可选优化，首版可略。

### 4.4 与敌人状态机集成

`stepEnemy` 中，仅 `approach / engage` 阶段接入寻路：

| 阶段 | 移动目标 | 是否寻路 |
| --- | --- | --- |
| approach（视线外，高速接近） | 玩家 / waypoint | 是 |
| engage（进入视线后慢速） | 玩家 / waypoint | 是 |
| orbit（绕玩家旋转） | 绕玩家切线 | 否（直接旋转） |
| charge（进阶1 冲刺） | 玩家 | 否（直线冲刺） |

- 寻路逻辑封装为 `moveTowardWithPath(e, speed, sec)`，内部决定"朝玩家"还是"朝 waypoint"。
- orbit / charge 阶段直接调用原 `moveToward`，清空 `path`。

## 5. 触发器事件系统

### 5.1 触发检测与重复机制

现有检测为"进入即触发一次"（`this.triggered` 集合去重）。扩展为支持可重复：

```js
// update 中，每个 trigger：
const inside = hitTrigger(t, this.player.x, this.player.y);

if (t.once) {
  // 一次性：触发过即跳过
  if (this.triggered.has(t.id)) continue;
  if (inside) { this.fireTrigger(t); this.triggered.add(t.id); }
} else {
  // 可重复：上升沿触发（外 → 内），受冷却约束
  const state = this.triggerState.get(t.id) || { inside: false, lastFire: -1e9 };
  if (inside && !state.inside && this.time.now - state.lastFire >= (t.cooldown || 0)) {
    state.lastFire = this.time.now;
    this.fireTrigger(t);
  }
  state.inside = inside;
  this.triggerState.set(t.id, state);
}
```

`triggerState` 在 `restart()` 时重置。

### 5.2 事件分发

```js
fireTrigger(t) {
  switch (t.action) {
    case 'complete':      // 既有通关语义
      this.state = 'end';
      ctx.onLevelResult?.('completed');
      break;
    case 'spawnEnemy':
      this.triggerSpawnEnemy(t);
      break;
    case 'switchLevel':
      ctx.onSwitchLevel?.(t.target, t.spawnPoint);   // 交外层加载关卡
      break;
  }
}
```

## 6. 召唤敌人事件

### 6.1 屏幕外生成（`mode: 'offscreen'`）

- 取当前相机可视矩形 `v = viewRect()`（世界坐标，含缩放修正，复用本次已新增的 `viewRect()`）。
- 屏幕外 10px：10px 为屏幕像素，需按缩放换算成世界距离 `offset = 10 / cam.zoomX`。
- 在 `v` 外扩 `offset` 后的矩形边界上随机取点（随机选上下左右四条边之一，再在该边上随机取横/纵坐标），保证恰好在屏幕外 10px。
- 校验与重试（最多 8 次）：
  1. 点须落在世界边界内，超出则 clamp；
  2. 点不得落在任何膨胀后的墙体内（`hitWall` 判矩形包含）。
- 通过校验后，生成 `count` 个 `enemyType` 敌人（`initEnemy` 初始化），`push` 到 `this.enemies`。

```js
spawnOffscreen(t) {
  const v = this.viewRect();
  const off = 10 / this.cameras.main.zoomX;
  const cfg = t.spawn;
  for (let i = 0; i < cfg.count; i++) {
    let p = null;
    for (let attempt = 0; attempt < 8 && !p; attempt++) {
      const candidate = sampleRingPoint(v, off, this.worldSize());
      if (!this.pointInWall(candidate)) p = candidate;
    }
    if (p) this.enemies.push(this.initEnemy({ x: p.x, y: p.y, type: cfg.enemyType }));
  }
}
```

`sampleRingPoint(v, off, world)`：外扩矩形边界随机采样并 clamp 到世界范围。

### 6.2 玩家周围生成（`mode: 'surround'`）

生成特效为独立运行时对象 `SpawnEffect`：

```js
{
  shape: 'polygon' | 'circle',
  sides: 6, radius: 120, thickness: 10,
  drawDuration: 500, fadeDuration: 500,
  enemyType: 'basic1', circleCount: 8,
  phase: 'draw' | 'fade',
  progress: 0,           // 0..1
  spawned: 0,            // 已生成敌人计数
  startAngle: -Math.PI / 2,  // 起始角（正上方）
  cx: player.x, cy: player.y  // 触发时玩家位置（特效期间固定，不跟随玩家）
}
```

顶点角度（顺时针，屏幕坐标下正角即顺时针）：

```js
// polygon：第 i 个顶点
angle(i) = startAngle + i * 2π / sides
// circle：第 i 个生成点
angle(i) = startAngle + i * 2π / circleCount
```

**绘制阶段**（`progress` 0→1，`drawDuration`）：

- 已绘制角度区间 = `[startAngle, startAngle + progress * 2π]`。
- polygon：逐边绘制，边 `i` 覆盖到即用 `lineStyle(thickness)` 画线段（顶点 `i` → 顶点 `i+1`）；当一个顶点首次被覆盖（ 越过 `i / sides`）时，在该顶点世界坐标生成敌人。
- circle：用 `arc` 绘制 `[startAngle, startAngle + progress * 2π]` 的圆弧（`lineStyle(thickness)` 描边）；当 `progress` 越过 `i / circleCount` 时生成敌人。

**消失阶段**（`progress` 1→0，`fadeDuration`，顺时针擦除）：

- 已绘制角度区间随 progress 收缩为 `[startAngle, startAngle + progress * 2π]`，即从起点开始顺时针逐段擦除。
- 消失阶段不生成敌人。

**推进与绘制**：

- `update()`：`progress += dt / 当前阶段时长`，draw 完成切 `fade`，fade 完成移除特效。
- `draw()`：在世界层 `g` 上按 `progress` 绘制多边形/圆弧（置于敌人下层即可）。

顶点生成敌人（顶点世界坐标 = `cx + cos(angle)*radius, cy + sin(angle)*radius`），直接 `initEnemy` + `push`。生成位置在玩家周围空旷处，通常不落墙；为稳妥可复用 `pointInWall` 校验，落在墙内时沿半径方向微调。

## 7. 切换关卡事件

### 7.1 渐变过渡状态机

在场景状态中新增 `transition`（或 `switching`）状态：

```
playing ──trigger(switchLevel)──▶ transition:fadeOut ──▶ 加载目标关卡 ──▶ transition:fadeIn ──▶ playing
```

- `fadeOut`：全屏黑色遮罩 alpha 0→1（时长可配，默认 500ms）。
- 加载：调用外层 `ctx.onSwitchLevel(target, spawnPoint)`，由 `main.js` 复用现有 `loadLevel` / `selectLevel` 完成数据替换，场景 `restart()` 重建敌人/玩家，玩家位置设为 `spawnPoint` 或目标关卡 `spawn`。
- `fadeIn`：遮罩 alpha 1→0。

### 7.2 实现

- 遮罩用屏幕空间 `uiG` 绘制（`fillRect(0,0,VIEW_W,VIEW_H)` 黑色，alpha 动态），置于 UI 之上。
- `ctx.onSwitchLevel` 回调由 `main.js` 提供，负责：
  1. 取目标关卡数据（`loadLevel(target)`）；
  2. `state.level = normalizeLevel(data)`，更新 `state.levelId`；
  3. 通知场景执行 `restart()` 并携带过渡信息（出生点覆盖）。
- 为避免加载竞态，过渡由场景驱动：`fadeOut` 结束 → 场景调用 `ctx.onSwitchLevel` → 外层同步完成数据替换 → 场景立即 `restart()` → `fadeIn`。

## 8. 编辑器改造（`src/main.js`）

触发器属性面板扩展，与敌人一致使用嵌套字段 `setNested`：

- `action`：下拉（complete / spawnEnemy / switchLevel）。
- `once`：布尔（一次性 / 可重复）。
- `action = spawnEnemy` 时显示：`mode`、`enemyType`（下拉）、`count`、`shape`、`sides`、`radius`、`thickness`、`drawDuration`、`fadeDuration`、`circleCount`。
- `action = switchLevel` 时显示：`target`（下拉，复用关卡列表）、`spawnPoint.x`、`spawnPoint.y`。

字段按 `action` 动态显隐（切换 action 时重渲染属性面板）。

## 10. 边界情况与后续

- **无路径**（敌人被全封闭）：A* 失败退回直冲，保证敌人仍可移动、不会卡死。
- **玩家贴墙**：终点取玩家最近可走格子，避免寻路死锁。
- **特效期间玩家移动**：特效多边形中心在触发瞬间固定，避免顶点跟随玩家抖动。
- **切换关卡在触发器内连续触发**：`once` 默认 true，天然防重；`switchLevel` 建议强制一次性（文档约定 `once` 对 switchLevel 始终按一次性处理）。
- **屏幕外生成点被墙占用**：重试 + clamp 兜底；极端情况（视口外全是墙）允许落在可走区边缘，优先保证生成成功。
- 后续事件（待补充）沿用 `action` + 独立配置子对象的结构，`fireTrigger` 中加分支即可。

## 11. 验收要点

1. 敌人被墙遮挡时沿路径绕墙，不再穿墙；视线通畅时直接冲向玩家。
2. 屏幕外生成：敌人出现在屏幕外 10px 处，不落在墙内。
3. 周围生成：多边形 0.5s 顺时针绘完，顶点逐个生成敌人，随后顺时针消失；圆形按配置数量均分生成。
4. 切换关卡：触发后渐变消失 → 加载目标关卡 → 渐变显现，玩家落在配置出生点。
5. 可重复触发器：每次进入（含冷却）触发；一次性触发器整关只触发一次。
