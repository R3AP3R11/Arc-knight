## 2. 现状与差距

现状（`src/editor/artboard.js` 518 行 + `src/systems/art/asset-render.js` 165 行）：

- 独立画板：仅「点击加点（30px 网格吸附）+ Ctrl+Z 撤点 + Enter 完成」，点不可选中/移动，无参考图形，无颜色/粗细/闭合/填充编辑，无整条变换。
- 主画板 stroke 元素：字段只有 color/lineWidth/rotSpeed/dir/phaseDeg/closed；**无 fill UI、无 orbitRadius 生效**（normalizeElement 归一化了 orbitRadius 但 stroke 渲染分支与 elementCenter 均未使用）；无缩放/旋转手柄（polygon 有 rim 手柄，stroke 没有）。
- 后端：只有 `/api/assets`（设计稿），无独立轮廓存储。

## 3. 总体设计

### 3.1 数据模型

**stroke 元素新增/启用字段**（`asset-render.js:normalizeElement` 已有字段定义，本迭代让它们生效/可见）：

| 字段 | 语义 | 兼容性 |
|---|---|---|
| `orbitRadius` | 公转轨道半径：>0 时轮廓**重心挂到轨道上**（沿 `ga` 方向偏移 `orbitRadius*s`），轮廓点相对重心排布并绕重心自转；**=0 保持旧行为**（点相对圆心自转） | 旧设计稿 orbitRadius 均为 0，渲染结果不变 |
| `fill` | 填充色（`closed && fill` 时 fillPath，渲染层已支持） | 仅补 UI |

**新轮廓资产 JSON**（存 `data/outlines/<id>.json`）：

```js
{ id: 'outline-<ts>', name: '轮廓名',
  points: [{x,y}, ...],        // 相对轮廓重心的点集（保存时平移到重心坐标系）
  color: '#ffa914', lineWidth: 4, closed: false, fill: null }
```

`normalizeOutline(raw)` 纯函数导出自 `asset-render.js`（无依赖叶子）。

### 3.2 独立画板（新模块 `src/editor/draw-board.js`）

> artboard.js 将超 600 行约定，独立画板整块抽出新模块，`artboard.js` 只留接线。

#### 3.2.1 工具条布局（#artDrawBoard 内，分组）

```
[模式] 加点 | 选择
[画笔] 颜色 粗细 ☑闭合 ☑填充 填充色
[插入图形] (圆形/圆弧/正多边形 ▾) 半径 边数 弧角°  [作参考底图] [转为轮廓点]
[参考轮廓] (已注册轮廓 ▾)  [作参考底图] [转为轮廓点]  [清除参考]
[选中点] X[ ] Y[ ] [删除点]          （选择模式下显示/启用）
[整条变换] 旋转°[ ] 缩放%[ ] [应用]
[库] 名称[ ] [保存为轮廓]
[原有] 网格吸附 | 撤销 | 清空 | 取消 | 完成
```

#### 3.2.2 交互规则

- **模式**：`add`（默认）/`select` 双按钮切换。点击已有点（命中阈值 8px）无论模式均选中；点击空白：add 模式=加点（沿用网格吸附），select 模式=取消选中。
- **选中点**：
  - 鼠标拖动移动（跟随「网格吸附」开关）；
  - **方向键每次移动 1 像素（不吸附）**；
  - XY number 输入框直接改坐标（画布坐标，相对画板圆心）；
  - Delete 键或「删除点」按钮删除；删除后选中取消。
- **Ctrl+Z** 维持「撤销最近添加的点」语义不变；选中点的删除走 Delete/按钮（移动不做撤销栈，轻量优先）。
- **参考图形**：
  - 参数生成：圆形（等分 24 点）、圆弧（弧角范围内等分 12 点）、正多边形（边数即点数）；
  - 「作参考底图」→ 半透明青色描边显示（不进 points），支持叠多个，画布右上角不遮挡；「清除参考」一键清空；
  - 「转为轮廓点」→ 生成的等分点 **push 进 drawPoints 末尾**（即追加到轮廓尾部）。
  - 「参考轮廓」下拉：`GET /api/outlines` 列表 → 同样两种用途；转为轮廓点时把其点集并入（相对重心）。
- **整条变换**：旋转（°）/缩放（%）填值后点「应用」→ 以**轮廓重心**为中心烘进点坐标：`p' = R(θ)·S(k)·(p-c) + c`。应用后输入框清零。
- **完成/保存**：
  - 「完成」→ 现有逻辑（≥2 点写入选中 stroke 元素或新建），并带上工具条当前的颜色/粗细/闭合/填充；
  - 「保存为轮廓」→ 名称非空校验 → `normalizeOutline`（点平移到重心坐标系）→ `saveOutline` → 刷新「参考轮廓」下拉 → setStatus 提示。

### 3.3 主画板（artboard.js）

- **stroke 字段补齐**（`elementFields` stroke 分支）：轨道半径 `orbitRadius`（number）、填充开关 `fillOn`（复用现有 key，stroke 也显示）、填充色 `fill`；`fillOn` oninput 分支已存在，stroke 走通即可。
- **stroke 手柄**（对齐编辑器实体手感）：
  - 缩放手柄：沿 `ga` 方向、距重心「最远点距离」处画黄色圆点；拖动 = 点集相对重心等比缩放（烘进 points，最小 0.05）；
  - 旋转手柄：缩放手柄外侧延伸 28px（沿用 `ROTATE_HANDLE_OFFSET` 惯例）；拖动 = 调 `phase`（5° 吸附，与编辑器一致），`ga = phase + rotSpeed*t*dir` 需扣除当前 simT 转角。
- **轮廓库接入**：`#artOutlineSelect` 列出 `/api/outlines`，「+ 从轮廓库添加」→ `loadOutline` → `normalizeOutline` → push 新 stroke 元素 `{shape:'stroke', points, color, lineWidth, closed, fill, rotSpeed:0.5, phase:0, orbitRadius:0}` 并选中。
- 拖动 stroke 元素（现有 `drag.mode='move'` else 分支改 orbitRadius/phase）在 orbitRadius 生效后自然可用，验证即可。

### 3.4 后端（server.js + api.js）

- `dirs.outlines = dataRoot/outlines` + `fs.mkdir`；路由 `parts[1]==='outlines'`：
  - `GET /api/outlines` → `{outlines:[{id,name}]}`（仿 assets 实现）；
  - `GET/POST/DELETE /api/outlines/:id`（id 过 `/^[-\w]+$/`）；
- `readOnlyDenied` 补 outlines 的 POST/DELETE（打包端只读）；
- `api.js` 加 `listOutlines/loadOutline/saveOutline/deleteOutline`。
- ⚠️ 坑15：路由内局部变量避开 `list/file/body/json`。

## 6. 风险与既知坑（实施时必读）

1. **坑17**：独立画板 Ctrl+Z 与编辑器关卡撤销的 document keydown 分流已存在（`bindings.js:321` artboard-mode 早退），T3 抽模块时**不得破坏**；新加方向键/Delete 也在 `drawBoardOpen` 守卫内。
2. **坑16**：新增 DOM id 必须同步 `src/ui.js` ids，否则 `getDom()` throw。
3. **坑18**：`normalizeElement`/`normalizeDesign` 返回新对象——事件 handler 内一律重新 `design.elements[index]` 取值，不捕获旧引用。
4. **坑15**：server.js 路由内局部变量避开 `list/file/body/json`。
5. stroke orbitRadius>0 时 `elementCenter` 返回的重心中心也必须含轨道偏移，否则主画板命中/手柄错位。
6. 旋转手柄调 phase 的换算：`phase = atan2(dy,dx) - handleAngleOffset - simT*rotSpeed*dir`（对齐现有 polygon move 分支写法）。
7. 轮廓点保存到库时平移到重心坐标系；从库添加时直接使用（stroke 渲染本就相对重心当 orbit>0；orbit=0 旧行为下重心偏移会在画布上体现为整体平移，属预期）。
